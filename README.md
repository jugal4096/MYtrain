# 🚆 MYtrain — Railway Information Interface

A web-based railway project built with HTML, CSS, and JavaScript. The repository includes dashboard and route pages, with railway station data used by the interface.

## ✨ Project Areas
- Railway-focused dashboard interface
- Route-related pages and interactions
- Station data stored in JSON
- Responsive styling and client-side JavaScript

## 🧰 Tech Stack
- HTML
- CSS
- JavaScript
- JSON

## 🚀 Run Locally
Clone the repository and open `index.html` in a browser. Some features may require a local web server depending on how the data files are loaded.
